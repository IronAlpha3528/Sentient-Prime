# Unified Evidence Framework (UEF)

## Overview
The Unified Evidence Framework standardizes inputs from all specialist ML detectors into a single schema boundary between ML detection and AI reasoning. It ensures that downstream AI and correlation engines operate on consistent, normalized data.

## Base Evidence Schema
Every piece of telemetry from detectors is mapped to `BaseEvidence`, which includes:
- **Incident ID / Identifier**
- **Entities**: Affected users, hosts, IPs, and OT assets.
- **Specialist Scores**: Network, Identity, Endpoint, OT sub-scores.
- **Deception Status**: Whether an active decoy has been touched.
- **Candidate Techniques**: MITRE ATT&CK techniques identified.
- **Unified Threat Score**: A combined score generated by the Meta-Classifier.

## Evidence Bus
The `EvidenceBus` is a thread-safe, in-memory streaming bus featuring:
- **Validators & Normalizers**: Ensures data adheres to schemas.
- **SHA-256 Deduplication Cache**: Prevents duplicate evidence from triggering multiple reasoning pipelines.
- **Priority Queue**: Sorts events by timestamp and priority for processing.

## Cyber Knowledge Graph
The UEF integrates tightly with the Cyber Knowledge Graph (built on NetworkX), which tracks entities (Users, Hosts, Processes, PLCs) and edges (CONNECTS_TO, RUNS_PROCESS, AUTHENTICATES_TO) to calculate centrality, blast radius, and topological features.
