# Correlation Context Schema Contract

This document specifies the format, fields, and example payload of the **CorrelationContext** object generated by the `ContextBuilder`. This object acts as the primary prompt injection block for downstream AI modules.

---

## Schema Fields

| Field Name | Type | Description |
| :--- | :--- | :--- |
| `context_id` | `str` | Globally unique UUIDv4 identifier of the context query. |
| `entity` | `str` | Node ID of the target root entity. |
| `time_window` | `Tuple[str, str]` | ISO timestamps of the context window (start, end). |
| `related_entities` | `List[str]` | Node IDs connected within the sub-graph. |
| `related_events` | `List[Dict]` | Edge relationship dictionaries in the local sub-graph. |
| `graph_paths` | `List[List[str]]` | Topological shortest paths from the root entity to related nodes. |
| `risk_summary` | `str` | Deterministic natural language summary of the threat narrative. |
| `supporting_evidence`| `List[Dict]` | Telemetry findings from graph nodes. |
| `timeline` | `List[Dict]` | Chronologically sorted chronological log of findings. |

---
